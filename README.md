# Smart Notes Organizer

Smart Notes Organizer is a lightweight web application designed to help users create, view, edit, and organize notes efficiently.

## 📁 Repository Structure

```text
Smart-Notes-Organizer/
│
├── templates/        # HTML templates for rendering pages
├── .gitignore        # Files ignored by Git tracking
├── app.py            # Main application script (Flask backend)
├── edit.html         # Page interface for editing notes
└── README.md         # Project documentation
🚀 Features
Create & Edit Notes: Easily draft new notes or update existing ones.

Organized Storage: Keeps notes categorized and cleanly accessible.

Simple Web Interface: Intuitive navigation powered by HTML templates and Flask.

🛠️ Tech Stack
Backend: Python (Flask)

Frontend: HTML5, CSS3

Version Control: Git & GitHub

🔧 Getting Started
Prerequisites
